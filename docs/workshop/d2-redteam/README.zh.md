# D2 红队材料包 —— 教师专用

> **先隔离。** 这个目录里的所有内容都是一份教学材料。`report.html` 是一份
> **刻意做假**的基金报告：机构是虚构的，里面每一个业绩数字都是编的。它绝不能
> 被引用进 `CLAIMS.md`、`README.md`、`reports/` 或学生的审计报告 —— 那些是本
> 仓库的唯一事实来源，而这里只是一件道具。
>
> 开课前请把这个目录整个从学生 fork 里删掉（workshop README 的 D2 一节已写明）。
> 如果学生翻了源码、看到 `d2-redteam-plant` 标记，也没关系：练习要找出的是
> **埋了哪些**偏差，而不是这份报告是不是假的。

## 这 40 分钟怎么走

| 分钟 | 做什么 |
|---|---|
| 5 | 发打印稿。只说一句：*"一个朋友转给我的，找出它的问题。"* 不放 PPT。 |
| 20 | 两人一组，**不许用电脑**。要求写**原话引用**，不是印象。 |
| 10 | 把各组找到的数量写到黑板上。中位数通常是 3 个；答案卡有 11 个。 |
| 5 | 收在 probe 6：诚实系统的 **t = 0.23**；这份报告在试了 **34 次之后**声称 **t = 2.0**。新因子的门槛是 t > 3.0。 |

然后说出这一周的地基那句话：*这一周不产生可实盘的策略，只产生一个能被审计的系统。*

## 学生计分卡（写到黑板上 —— 不是答案）

| 偏差类别 | 该问的问题 |
|---|---|
| 时点（PIT） | 打分的那一刻，这些数字已经公开了吗？ |
| 执行 | 哪个价格、哪一天、哪个时间戳？ |
| 成本与费用 | 毛的还是净的 —— 扣的是**谁的**费？ |
| 股票池 | 样本里被删掉了谁？ |
| 基准 | 价格指数还是全收益？同一个窗口吗？ |
| 选择 | 在留下这一组之前，试过多少组？ |
| 算术 | 附录、曲线、标题数字，三者对得上吗？ |
| 可复现 | 你能用对方给的文件把它重算出来吗？ |
| 风险 | 风险指标和最差单月自相矛盾吗？ |

只找到三个一眼可见的（前视、无成本、幸存者宇宙）的小组，只完成了一半。
另外八个都要翻附录。

## 为什么它"够难"

- 曲线、年度表、月度热力图是**同一组内部自洽的序列**（12.5 年 CAGR 19.0%、
  波动率约 11%、回撤 −15.8%）。附录里没有任何粗糙的算术错误，所以不能一句
  "算错了"就打发了。
- 谎话藏在**标签、方法与免责小字**里：3 个一眼可见、6 个中等、2 个隐蔽。
- 有两个陷阱只奖励翻了附录的人：标题数字是 7 年**实盘**窗口，不是
  "since inception 2014"；声称的 −8.9% 最大回撤，比热力图里印着的 −11.2% 单月
  跌幅还小。
- 本仓库的诚实数字是对照组 —— CAGR 14.47%、t = 0.23、probe 6 FAIL。最后五分钟
  跑一次 `make audit`，让学员带着对比离开，而不是只带着一个把戏。

## 重新生成与校验

```bash
python docs/workshop/d2-redteam/kit.py build   # report.html + 两份答案卡
python docs/workshop/d2-redteam/kit.py check   # 原话还在？中英同步？没泄漏？
python docs/workshop/d2-redteam/kit.py dump    # 附录里的真实数字
```

`check` 会在以下情况失败：某个埋点的原话从 `report.html` 里消失了、两份答案卡
不同步、或者编造的标题数字泄漏进了 `CLAIMS.md`、`README.md`、`LEARNING_PATH.md`、
`AGENTS.md`。每次开课前都跑一遍 —— 这就是 `make validate` 那套纪律，用在文档上。

## 不要做

- 不要把这个目录里的数字引用到任何其它地方；
- 不要把 `answer-key.*` 或 `biases.json` 发出去；
- 不要手改 `report.html` —— 它是生成的，`build` 会覆盖；
- 不要为它写假设卡：它是道具，不是策略（`AGENTS.md` 第 1 条管的是真实想法，
  不是诱饵）。
