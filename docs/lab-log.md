## 记录规则

1. 一次只改一个参数；改了第二个，就不知道是谁的功劳。
2. "我的预测"必须写在跑之前。
3. 结论栏只能写三选一：**采纳 / 拒绝 / 无法判定**。写"看起来不错"视为没写。
4. 任何"采纳"都必须能通过 `make audit` 六项。
